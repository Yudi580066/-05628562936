# JAPAN SCENE

映画・アニメの舞台や観光地をめぐるツアーサイト。HTML・CSS・JavaScriptだけで動く静的サイトです。ビルドや追加パッケージは不要です。

## 編集するファイル

- `お試し.html`：ページ本体。デザイン・プラン・料金・カレンダーの編集先です。
- `素材/`：使用中の画像。フォルダー構成とファイル名を維持してください。
- `index.html`：トップURLからページ本体へ移動する入口です。
- `.nojekyll`：HTMLと画像をそのまま公開するための設定です。
- `favicon.ico`・`素材/icons/`：JAPAN SCENEのページアイコンです。HTMLと一緒に公開してください。

`index.html`にページ本体をコピーする必要はありません。今後も`お試し.html`を編集し、変更したファイルをGitHubへ反映してください。

## ページアイコン

白い正円に黒い大文字Jを配置しています。Jは既存フォントを使わず、右上の斜めカットと広めの下フックを持つ独自パスで作成。ネットで既存例を調べて字形を比較していますが、世界中の既存デザインとの不一致を保証するものではありません。`お試し.html`・`index.html`の両方に設定済みです。SVG、32px PNG、16/32/48px ICO、180pxのホーム画面用PNG、再利用用512px PNGを用意しています。更新後に古いアイコンが残る場合は、タブを閉じて開き直してください。

## 表示言語

ページ上部のEN・PT・JPで英語・ブラジルポルトガル語・日本語に切り替えられます。選択言語は利用中のブラウザーに保存されます。日付・行き先・人数・入力したご希望は、言語を変えても保持されます。料金は各言語とも米ドル（USD）です。

翻訳は`お試し.html`末尾の`siteLanguages`内で管理しています。写真や地図の画像に含まれる文字は翻訳されません。外部の翻訳サービスや追加ファイルは不要です。

## GitHub Pagesで公開

1. GitHubのリポジトリの直下に、このフォルダーの中身をアップロードします。`index.html`、`お試し.html`、`素材/`、`.nojekyll`を同じ階層に置きます。
2. リポジトリの **Settings → Pages** を開きます。
3. **Source** を **Deploy from a branch** に設定します。
4. アップロード先のブランチ（通常は`main`）と **/(root)** を選び、**Save** を押します。
5. デプロイ完了後、Pages画面の **Visit site** から確認します。

設定手順：[GitHub公式ドキュメント](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 現在の予約機能

日付・行き先の選択、人数・日付別料金の計算、予約内容の表示まで対応しています。予約情報の送信・保存、予約の確定、決済は未実装です。再読み込みすると選択内容は消えます。

## ローカル確認

`index.html`をブラウザーで開くとページ本体に移動します。Pythonがある場合は、このフォルダーで次のコマンドを実行しても確認できます。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザーで`http://127.0.0.1:8000/`を開きます。終了はターミナルで`Ctrl+C`です。

## 料金設定（USD）

全プラン共通で1組・1日：通常平日は6歳以上1〜2名US$299。6歳以上の3〜9人目は1名につきUS$50、10人目以降はUS$100追加（5歳以下を含め最大15名）。

- 土日・日本の祝日：US$30追加。
- 繁忙日（3月20日〜4月10日、4月29日〜5月5日、8月13日〜16日、12月24日〜25日）：US$60追加。
- 年末年始（12月29日〜1月3日）：US$90追加。
- 日付加算は1組あたりで、重複時は最高額だけを適用。人数加算は毎日適用。
- カスタマイズは選択した各日の合計。訪問先を4か所未満にしても減額しません。

`PRICING`と`pricing()`が計算の共通設定です。金額を変更する場合は、カードの基本料金、`pricingGuideTemplate`の説明、EN/PT翻訳も更新してください。

祝日は[内閣府](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html)の2026・2027年公表分（振替休日・国民の休日を含む）を反映しています。予約可能期間は日本時間の本日から8か月先まで（`BOOKING_MONTHS_AHEAD`、`latestBookableDate()`）。祝日データは2027年までのため、受付期間が2028年に入る前に`JAPAN_HOLIDAYS`を更新してください。

米ドル表示への変更は決済導入ではありません。Squareの日本アカウントは日本円決済のため、導入時には最終的な円請求額・換算方法を別途設定する必要があります。

両カレンダーでは土日・日本の祝日・繁忙日の日付を赤く表示します。選択中は淡い赤、選択不可は落ち着いた赤とグレー背景になり、日付の区分はツールチップ・読み上げラベルでも確認できます。

## 日付選択と集合場所

予約日は日本時間の本日から3日後〜8か月先です（例：2026年10月4日なら10月7日〜2027年6月4日）。8か月後に同じ日がない場合は月末を上限にします。`BOOKING_LEAD_DAYS`と`earliestBookableDate()`で共通判定し、米国・ブラジルのブラウザーでも同じ受付日になります。最初に表示する月は最短予約日の月です。

カスタマイズプランでは、各日の集合・解散場所に駅のほか「現地」を選べます。おすすめプランの集合・解散場所は従来どおり固定です。

## おすすめプランの行程・受付曜日

ツアーは13:00〜20:00です。集合13:00、到着推奨12:50、遅刻連絡の期限12:30、待機終了13:20で各言語の案内を統一しています。「ご参加前の注意事項」の見出しは削除し、注意事項の本文は掲載しています。

おすすめプランは6件です。「上野・アメ横・浅草・スカイツリーツアー」「お台場・東京タワー・ラーメン博物館ツアー」「横浜・みなとみらい満喫ツアー」などを掲載しています。料金は他のプランと同じ共通ルールです。

- 上野・浅草：上野駅集合 → 上野（動物園・科学博物館・東京国立博物館）→ アメ横 → 雷門・仲見世 → スカイツリー → 押上駅解散。上野の入館先・滞在時間は休館日と希望により調整します。スカイツリーの画像は表示しません。
- お台場・東京タワー・ラーメン博物館：東京テレポート駅集合 → お台場 → 東京タワー → 新横浜ラーメン博物館 → 新横浜駅解散。施設の営業時間・休館日・混雑に応じて滞在時間を調整します。
- 横浜：横浜駅集合 → 帆船日本丸 → ランドマークタワー → YOKOHAMA AIR CABIN → コスモワールド → カップヌードルミュージアム → 赤レンガ倉庫 → 中華街 → 元町・中華街駅解散。

横浜だけ `closedWeekdays: [2, 4]`（火曜・木曜）で受付不可です。`isPlanBookableDate()` をカレンダーの無効化・クリック・予約追加の各処理に使用しています。他のおすすめプランとカスタマイズの曜日選択には影響しません。祝日の火曜・木曜も受付不可です。施設の臨時休館日・振替休館日は自動取得せず、サイト上では外観散策などへの変更を案内しています。

2026年10月2日確認：ランドマークの[スカイガーデン](https://yokohama-landmark.jp/skygarden/)は休館中のため入場を行程に含めていません。[帆船日本丸](https://www.nippon-maru.or.jp/userguide/)は月曜などの休館日は外観散策。[カップヌードルミュージアム](https://www.cupnoodles-museum.jp/ja/yokohama/guide/admission/)は振替休館もあるため個別確認が必要です。


## 人数区分・最新の行き先

サイトでは「5歳以下は無料。」と表示し、無料児童の人数欄は設けていません。参加人数は6歳以上だけを入力し、その人数で1〜2名299ドル、3〜9人目50ドル、10人目以降100ドルを計算します。通常平日の例：9名649ドル、10名749ドル、15名1,249ドル。

総人数の代わりに有料人数を`qty`へ保持します。`validParty`が6歳以上1〜15名の整数を検証し、`pricing`を両カレンダーと日別合計で共用します。5歳以下の人数は取得せず、無料児童を含む総人数の自動判定は行いません。

カスタマイズは`MAX_CUSTOM_DAYS = 7`により最大7日、1日最大4エリアです。日数に応じた日付数を選び、最初と最後の日付の差は従来どおり7日以内です。

エンタメツアーは池袋駅集合・アニメイト池袋本店 → 中野 → 渋谷 → 秋葉原。ポップカルチャーツアーは原宿の次に「神宮前：ハラカド・オモカド」の独立した見出しと説明を追加しています。

カスタマイズは18エリア。上野の動物園・博物館とアメ横は別々に選択できます。みなとみらい・赤レンガ倉庫・銀座はカスタマイズの選択肢から外しています。豊洲（チームラボ）はカスタマイズ・おすすめの両方から外しています。画像のない場所は説明と地図を表示します。

地図は東京側が `素材/ChatGPT Image 2026年9月22日 16_32_03.jpg`（658×719）、横浜側が `素材/yokohama-area-map.jpg`（666×664）。新横浜・中華街は `mapRegion: "yokohama"` で切り替えます。表示比率は両方658:719で、画像とSVGのピンを同じ中央トリミングに揃えています。`mapPoint` はおおよその表示座標です。ピンのアニメーションはアニメツアーを開くときだけです。

訪問先の注意事項から外部リンクを削除しました。注意事項本文は維持しています。

予約内容の合計下にガイド紹介（日本育ちのブラジル人、東京・横浜に詳しく英語は学習中）を表示します。18歳未満の同伴条件は参加前の注意事項へ移し、その複製を予約内容の同意事項にも含めています。年齢の自動判定は行わず、同伴条件の確認は注意書きと規約同意によります。20分間の待機・無連絡不参加の注意は予約内容の「交通費・集合時間・遅刻時の扱い」に集約しました。スマホでは言語切り替えとロゴの左端を揃えています。

カスタマイズの紹介文とカレンダー下部の長い説明を削除し、ご希望欄の例文はEN/PTに翻訳します。スライド下端の白いグラデーションを削除し、見出しを下寄せにしています。スマホは`touch-action: manipulation`でダブルタップ拡大を抑え、ピンチによる拡大は残しています。

初回表示は英語です。EN/PT/JPを選択した場合はその選択を保存し、次回も使います。スマホの日数・人数は横2列に配置。4枚のスライドはPC用とスマホ用の表示位置を個別に設定し、文字を読みやすくする暗いオーバーレイは維持しています。参照されていない画像3点と旧地図・人数表示の未使用コードを削除しました。

カスタマイズの行き先欄は1日目を初期状態で開いた折りたたみ表示、2〜7日目を初期状態で閉じた折りたたみ表示にしています。日数を減らした際は対象外の日の折りたたみを閉じ、選択内容は保持します。

おすすめプラン・行き先詳細・予約内容のダイアログ表示中は背景スクロールを固定し、閉じると元のページ位置へ戻します。ダイアログ内部はスクロールできます。

各観光先の詳細に「入場料の目安（1名・日本円）」を表示します。おすすめの各行程、アニメ聖地の選択カード、カスタマイズ全18エリアに対応しています。`admissionFees` を共通データとし、各行程・エリアの `admissionKey` で参照します。入場料はツアー料金に加算せず、別途必要な費用として案内します。確認日・変動料金・幼児も施設によって有料となる点をJP/EN/PTに記載。公式料金の確認記録は [admission-fees.md](admission-fees.md) を参照してください。

無料の街歩き・通常入店のみの行き先には入場料欄と料金注記を表示しません。有料施設がある行き先では料金欄を表示し、子ども等の無料対象は料金区分として残します。営業休止中のスカイガーデンは行程本文で案内します。

臨時休館・休業・運休や営業時間変更の可能性を、参加前の案内と各プラン・カスタマイズの詳細にJP/EN/PTで表示します。施設都合や天候で訪問先・行程を調整する場合があることも案内しています。

写真の表示枠はおすすめカード・行き先詳細・アニメのサムネイルを4:3に統一。詳細内では縦長・正方形に近い写真の全体を表示し、スマートフォンでは写真を1列で表示します。カスタマイズの選択ボタンには写真を表示せず、開いた詳細で読み込みます。追加写真は `素材/custom/` のWebPに軽量化しています。

参加人数の初期値と入力不正時の料金プレビューは1名。基本料金に含む人数は従来どおり2名です。

施設予約の確認記録は [reservation-notes.md](reservation-notes.md) を参照してください。
